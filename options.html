github-utils

Label criteria

Each criterion adds a column before the issue title, an entry in the Sort by menu, and click-to-filter on its values. Columns appear in the order below.

The pattern is a regular expression matched against the whole label name (case-sensitive). No capture group: the whole label is shown. One or more groups: the captures are shown, in order, joined by the separator.

Presets

A preset is a named set of criteria bound to repos. Tick the criteria a preset contains (a criterion can be in any number of presets) and list the repos it applies to, one shell pattern per line: owner/repo, owner/*, */*, w*/*github* (* matches any characters except /, ? one character; case-insensitive).

On a repo's issue list, the enabled presets that match the repo decide what applies: the criteria they contain, whatever each criterion's own Enabled switch says. With no matching preset, the criteria whose Enabled switch is on apply.

Export and import

Export writes the settings shown above (saved or not) to a JSON file. Import loads a file into the page; review it and click Save to apply.
